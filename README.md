# «Абай жолы» — оқу мен ойлау мектебі

М.Әуезовтің «Абай жолы» роман-эпопеясын (ІІІ–IV кітап) оқыту арқылы оқушыны оқу мен ойлауға баулу.
11-сыныпқа арналған элективті курстың электронды жұмыс дәптері (34 сабақ).

Авторы: Рыскелдиева Гульмира Даулетказиевна, ШЖҚ «М. Мақатаев атындағы №140 гимназия» МКК-нің
қазақ тілі мен әдебиеті пәні мұғалімі, педагог-шебер, «Үздік педагог-2015» байқауының жүлдегері,
«Ы. Алтынсарин» төсбелгі иегері, ҚР Білім беру ісінің Құрметті қызметкері.

## Бөлімдер
- Бағдарлама: паспорт, мақсат-міндеттер, 34 сағаттық тақырыптық жоспар
- 34 сабақ: үзінді, автотексерілетін тест, ашық сұрақ, кесте, дескриптор, рефлексия
- Сөздікқор: 76 көмескі сөз, «Сөзбіқор көмекшісі», карточкалар, ойын (sozdikqor.kz сілтемесімен)
- Әдістер кітапханасы, кейіпкерлер, портфолио, мұғалім кабинеті, жобаны дамыту жоспары

## Іске қосу
Сайт бір файлдан тұрады: `index.html`. Браузерде ашсаңыз жеткілікті.

GitHub Pages арқылы жариялау:
1. Репозиторийге `index.html` және `README.md` файлдарын жүктеңіз.
2. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
3. Бірнеше минуттан кейін сайт `https://<username>.github.io/<repo>/` мекенжайында ашылады.

Оқушы жауаптары тек өз браузерінде (localStorage) сақталады.
